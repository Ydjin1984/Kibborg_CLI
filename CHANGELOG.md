# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- **Видно, кто именно работает.** Лента подписывает строки агентом: значок `◆` открывает ветку с именем агента, его моделью и ролью (`ORCHESTRATOR` для сессии, в которую печатает пользователь, `EXECUTOR` для субагента, посаженного на локальный маршрут исполнителя, `SUBAGENT` для остальных), строки субагента идут с отступом `│`, а `└─ ✓` закрывает ветку. Имя субагента берётся из его дескриптора, из проекции `subagent` или — у одноразового исполнителя, который дескриптора не пишет, — из самого вызова `executor`. Цвет агента выводится из его имени, поэтому две модели в одном прогоне видны как два разных цвета. Данные берутся только из фактов хоста: списка сессий (`parentSessionId`, `origin`, `agentPreset`), событий `request/header` и `subagent/descriptor` в логе ребёнка и проекций `subagent`/`subagentActivity`; роль не выдумывается — при выключенном оркестраторе у корня её нет. Подписи отключаются `KIBBORG_NO_AGENTS=1`.

### Изменено

- **Кадр больше не пересобирает ленту целиком.** Транскрипт рендерится частями и переиспользуется, пока модель ленты не изменилась, а окно прокрутки берёт только видимые строки. На ленте в 3000 записей (16 000 строк) кадр без изменений подешевел с ~355 мс до ~0,13 мс, кадр во время потока — с ~339 мс до ~3 мс; кэш отрендеренных записей держит сессию целиком, а поток текста ответа больше не ищет свою запись по всей ленте.
- **`+N` и `−M` печатаются двумя цветами** (`+N` зелёным, `−M` красным) и в ленте, и в scrollback-режиме.

## [0.1.0] — 2025-09-12

Первая публичная версия CLI.

### Добавлено

- **Команда `kibborg` для любой оболочки**: `install.ps1` и `install.sh` создают шим, который запускает собранный `apps/cli/lib/bin.js`; PATH правится в пользовательской области, администратор не нужен.
- **Три режима работы**: интерактивный TUI (inline и `--fullscreen`), headless (`-p`, `--output-format text|json|stream-json`) и сетевой (`serve` на одной машине, `attach` к нему, `discover` через mDNS).
- **Палитра команд с подменю**: `/` открывает список, `/model`, `/effort`, `/permission`, `/resume` открывают выбор, строка `↩ назад` и `Escape` возвращают на уровень выше.
- **Лента инструментов целиком**: `IN` с полным JSON аргументов, `OUT` с полным ответом, diff со знаками `+`/`−` и сводкой `+N −M`, время вызова.
- **Markdown в ответах**: заголовки, списки, таблицы с выравниванием, блоки кода с рельсом, инлайн-код, ссылки.
- **Кликабельные ссылки и пути**: OSC 8 гиперссылки, `Ctrl`+клик открывает файл или URL.
- **Выделение и копирование**: протяжка мышью подсвечивает область и кладёт текст в буфер обмена в правильной кодировке (UTF-8 через `Set-Clipboard` на Windows).
- **Сворачивание длинных блоков**: записи длиннее 20 строк показываются началом и строкой «⋯ ещё N строк — клик, чтобы развернуть».
- **Живой интерфейс**: спиннер с меняющимся цветом, статусная строка, где модель, `ctx` и режим остаются видимыми во время хода, подтверждения действий исчезают через пять секунд.
- **Навигация**: стрелки прокручивают ленту на пустом вводе и листают историю на непустом; `Shift+Enter` переносит строку (Win32 input mode и kitty keyboard protocol), `Ctrl+J` — перенос в любом терминале.
- **Настройки и реестры**: секция `kibborg-cli` (тема, метки времени, многострочный ввод, режим экрана), `settings`, `auth`, `models`, `mcp`, `skills`, `tools`, `agents`, `jobs`, `commands`, `stats`, `doctor`, `export`.
- **Развёртывание**: `deploy/kibborg.service` (systemd), `deploy/Dockerfile`, `deploy/docker-compose.yml`, `deploy/healthcheck.sh`, примеры для GitHub Actions и cron.
- **Проверка качества**: 235 юнит-тестов, `oxlint` без замечаний, PTY-сценарии меню, команд и полноэкранного режима, инструмент кадров `tests/frame-render.mjs`.

### Безопасность

- `serve` отказывается стартовать на не-loopback интерфейсе без токена и печатает причину с кодом выхода 2.
- Гейт `/api` проверяет `Origin` и токен; без токена — 401.
- `--safe` применяет режим `Ask` к сессии даже если в настройках сохранён более широкий пресет.
