# Примеры запуска Kibborg CLI

English | [中文](README.zh.md)

Здесь лежат готовые заготовки для неинтерактивных сценариев: CI, cron и одноразовый Docker-запуск. Все три опираются на один контракт headless-режима:

- `stdout` — только результат (`--output-format text|json|stream-json`), человеческие строки идут в `stderr`;
- exit-коды: `0` — успех, `1` — ошибка (включая провалидённый `--json-schema` и исчерпанный `--max-turns`), `2` — ошибка конфигурации/окружения/задачи, `3` — требуется решение пользователя (вопрос без `--question-answers`), `130` — прерывание.

| Файл | Что показывает |
|---|---|
| `github-actions.yml` | шаг workflow: ответ в JSON, проверка схемой, публикация результата |
| `cron-kibborg.sh` | ночной запуск с `--max-turns` и логом в файл |
| `Dockerfile` | одноразовый контейнер с собранным CLI |

Перед первым запуском убедитесь, что профиль собран и ключ доступен: `kibborg doctor` и `kibborg auth`.
