# Анализ реализации функций в проекте Kibborg

## Найденные функции

### 1. Функция `render` из файла `app.ts`
Это функция, отвечающая за полную перерисовку интерфейса. Она создаёт полный буфер и перерисовывает весь экран с учётом всех элементов (заголовок, лог, панели, статус и т.д.).

### 2. Функции `moveSelection` и `moveTab` из файла `panel.ts`
Эти функции обрабатывают навигацию внутри панелей:
- `moveSelection` - перемещает выбор внутри активной вкладки панели
- `moveTab` - переключает между вкладками панели

### 3. Обработчики клавиш в `input.ts`
Корректно парсят стрелки вверх/вниз и другие клавиши.

## Проблема моргающих надписей

При нажатии стрелок в панели происходит полная перерисовка интерфейса, а не частичная. В файле `fullscreen.ts` (строки 437-438) при обработке клавиш стрелок в панели происходит следующее:

```typescript
case 'up': panel = movePanelSelection(panel, -1); render(); return
case 'down': panel = movePanelSelection(panel, 1); render(); return
```

Здесь `movePanelSelection` обновляет состояние панели и вызывает `render()`, что приводит к полной перерисовке всего интерфейса, а не только изменяемых элементов.

## Причина моргания

Полная перерисовка происходит потому что:
1. При нажатии стрелки в панели вызывается `movePanelSelection()`, который изменяет только выбор внутри панели
2. Затем вызывается `render()`, который перерисовывает весь экран целиком
3. Вместо того чтобы обновить только отображение панели и её текущий выбор, происходит перерисовка всех элементов интерфейса

## Рекомендации

Для устранения моргания нужно реализовать частичную перерисовку в `fullscreen.ts` при обработке стрелок панели, сохраняя текущую логику обработки событий, но используя более точную перерисовку, которая обновляет только изменённые элементы, а не весь интерфейс целиком.
