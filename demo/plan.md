# Анализ реализации функций в проекте Kibborg

## Цель
Проанализировать реализации функций:
1. Функцию `render` из файла `app.ts`
2. Функции `moveSelection` и `moveTab` из файла `panel.ts` 
3. Обработчики клавиш в `input.ts`, особенно обработку стрелок вверх/вниз
4. Логику обновления отображения при изменении выбора

## Ход работы
1. Найти и изучить указанные файлы
2. Проанализировать реализации функций
3. Найти места полной перерисовки вместо частичной
4. Выявить причину моргающих надписей при нажатии стрелок
5. Подготовить отчет

## Результаты
Анализ показал, что проблема моргающих надписей вызвана полной перерисовкой интерфейса при нажатии стрелок в панели вместо частичной перерисовки.
